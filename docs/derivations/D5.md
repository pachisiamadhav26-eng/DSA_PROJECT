# D5 AVL split and a rotation-heavy sequence

Module owner: Bianca (Bianca-the-sensational)

## Split by a key

For a cutoff key k, descend along its search path. If the root key precedes
k, split the right child and join the untouched left child, the root, and
the preceding part returned by recursion. Return that join and the other
part. If the root key equals or follows k, use the symmetric step on the
left child. The empty tree gives two empty trees. Induction on the path
shows that the results are disjoint, ordered and contain exactly the
original keys. Each join receives ordered arguments, so D1 guarantees
balance and correct heights and sizes.

## Why the join costs telescope

Write h(T) for AVL height. Both split outputs have height at most the input
height. To see this inductively, each join takes the untouched child and
a part of the searched child. Both have height at most h(T)-1, and D1
bounds the join height by one plus the greater input height.

On the way back up, track the two partial output trees. At each ancestor
exactly one partial output is joined with the root and the untouched child.
Let A be the old partial height, S the untouched child's height and B
the new partial height. The searched child had height at least A, and
AVL balance gave S >= A-1. Thus |S-A| is at most 1 + max(0,S-A).
Also B >= max(A,S) by D1, so that join costs O(1+B-A).

The constant part is charged once per ancestor. The other part telescopes
for each partial output separately because its height changes from A to B.
Each starts at zero and ends at at most h(T). Total cost is O(h(T)),
which is O(log n). Multiplying the worst-case cost of one join by the path
length would lose the overlap captured by this height accounting.

## A sequence that forces many rotations

Insert n distinct keys in increasing tree order. For this leaderboard, use
strictly decreasing scores. Each new leaf extends the right spine by one.
Any first unbalanced ancestor is right-heavy. The insertion followed only
right edges, and its right child grew towards its own right child. The
repair at that ancestor is one left rotation. It restores the old height
of that subtree, so no ancestor above it needs another rotation for this
insertion.

Each of these left rotations shortens the full right spine by exactly one.
The rotated root formerly lay on that spine and becomes the left child of
its former right child. If the final right spine contains r nodes and R
single rotations occurred, then r = n-R. Since r <= h(T) = O(log n),
R >= n-O(log n). At most one rotation occurred per insertion, so a
constant fraction of the insertions force rotations for sufficiently
large n. The descending-score generator supplies the order and the
backend counter measures the rotations.
